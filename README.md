# silqwer/homebrew-tap

Homebrew tap for [silqwer](https://github.com/silqwer)'s apps.

```bash
brew install --cask silqwer/tap/devservers
```

| Cask | Description |
|---|---|
| [devservers](Casks/devservers.rb) | macOS menu bar app that shows which local dev servers are running and on which port — [website](https://silqwer.github.io/devservers/) |
